# Picture Host - 个人图床

个人用图片存储仓库，用于存放和管理各类图片文件。

## 📁 目录结构

```
images/
├── avatars/     # 头像图片
├── screenshots/ # 屏幕截图
├── photos/      # 个人照片
├── icons/       # 图标文件
└── misc/        # 其他图片
```

## 🚀 使用方法

### 上传图片
1. 将图片文件放入相应的目录中
2. 建议使用有意义的文件名（如：`avatar_2024_01.png`）
3. 提交到仓库

### 获取图片链接
GitHub 提供了原始文件访问功能，可以直接通过以下格式获取图片链接：

```
https://raw.githubusercontent.com/ASSASSINs2066/picture-host/main/images/[目录]/[文件名]
```

示例：
```
https://raw.githubusercontent.com/ASSASSINs2066/picture-host/main/images/avatars/my_avatar.png
```

### 在 Markdown 中使用
```markdown
![描述文字](https://raw.githubusercontent.com/ASSASSINs2066/picture-host/main/images/avatars/my_avatar.png)
```

## 📋 支持的格式

- **PNG** - 推荐用于截图、图标
- **JPG/JPEG** - 推荐用于照片
- **GIF** - 动态图片
- **WebP** - 现代格式，体积小
- **SVG** - 矢量图形
- **BMP** - 位图格式

## 📝 文件命名建议

- 使用英文和数字
- 避免空格，使用下划线或短横线
- 包含日期：`screenshot_2024_01_15.png`
- 包含用途：`avatar_github.png`
- 保持简洁明了
